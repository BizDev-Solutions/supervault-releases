# Super Vault — releases

Public download channel for **Super Vault** Android builds. This repository holds
release files only (APK + `update.json`); it contains no source code.

Installed apps read `releases/latest/download/update.json` to learn about new
versions. A build below `minCode` must update before it can be used. Each APK is
checked against the SHA-256 in `update.json` before installation.

قناة التحميل العامة لإصدارات Super Vault على أندرويد. لا يحتوي هذا المستودع على أي كود، فقط ملفات الإصدار.
